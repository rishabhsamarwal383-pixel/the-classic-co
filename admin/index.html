Install Admin App on Phone / Desktop

The Classic Co. - Admin Operations PWA
Official App

Install this dashboard directly onto your Android phone, iPhone, or PC. It opens in full-screen standalone mode with real-time Shopify Cha-Ching order sound alerts, offline access, and fast 1-tap operation.

📱 How to install on mobile if the 1-Tap button is blocked:
🤖 Android (Chrome): 1. Tap Chrome's ⋮ (3 dots) menu in the top-right corner.
2. Tap "Install app" or "Add to Home screen".
3. The app icon with Instagram DP will be added to your home screen!
🍎 iPhone (Safari): 1. Tap Safari's Share button (square with arrow pointing up) at the bottom.
2. Scroll down and tap "Add to Home Screen".
3. Tap Add in the top-right corner!
